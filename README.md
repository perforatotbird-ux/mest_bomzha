# Platformer — заготовка 2D-платформера (Godot 4.7.2)

Персонаж — спрайты Drifter из `Assets/Drifter/` (кадры 384×512 из набора `drifter-sprites-alpha-cleaned`, прозрачный фон).

## Управление
| Действие | Клавиши |
|---|---|
| Бег влево/вправо | A / D (или стрелки) |
| Прыжок | Space / W / стрелка вверх |
| Приседание (удерживать) | S / стрелка вниз / Ctrl |
| Бросок по дуге | F — удерживать для превью траектории, отпустить для броска |
| Выстрел назад («пердёж») | G |

## Анимации
Ресурс `Assets/player_frames.tres` (SpriteFrames), 14 анимаций / 74 кадра:

| Анимация | Кадров | Скорость | Когда играется |
|---|---|---|---|
| idle | 6 | 8 fps | стоит на земле |
| walk | 8 | 8 fps | медленное движение |
| run | 8 | 12 fps | быстрое движение |
| crouch | 4 | 8 fps | приседание |
| crouch_walk | 6 | 8 fps | движение в приседе |
| jump | 6 | 8 fps | подъём в воздухе |
| fall | 3 | 8 fps | падение |
| landing | 3 | 8 fps | приземление (одноразовая) |
| throw | 6 | 8 fps | бросок бутылки (одноразовая) |
| rear_shot | 5 | 8 fps | выстрел назад (одноразовая) |
| drink | 6 | 8 fps | заготовка (механики выпивания нет) |
| hit | 3 | 8 fps | заготовка |
| death | 6 | 8 fps | заготовка |
| victory | 4 | 8 fps | заготовка |

Переключение состояний — в `scripts/player.gd` (`_update_animation`), одноразовые анимации — `_play_one_shot()`.
Спрайт отражается по направлению взгляда (`AnimatedSprite2D.flip_h`). Пивот кадра — (192, 464), поэтому центр спрайта поднят на `208 × scale` над линией земли (scale 0.22).

## Структура
- `scenes/main.tscn` — уровень: фон, пол, стены, 8 платформ, игрок
- `scenes/player.tscn` — персонаж: хитбоксы (стойка/присед), луч потолка, `AnimatedSprite2D`, маркеры рук, камера, превью траектории
- `scenes/platform.tscn` — универсальная платформа (`shape_size` и `color` задаются на инстансе)
- `scenes/projectiles/` — брошенный предмет и «выстрел назад»
- `scripts/` — контроллер игрока, платформа, снаряды
- `Assets/Drifter/frames/` — кадры Drifter по анимациям (прозрачный фон)
- `Assets/Bomzh/` — прежний набор спрайтов (не используется)

## Что уже настроено
- Койот-тайм (0.1 с), буфер прыжка (0.15 с), переменная высота прыжка, апекс-модификатор гравитации
- Присед: уменьшенный хитбокс + проверка потолка лучом перед вставанием
- Бросок: превью дуги (Line2D), совпадает с физикой снаряда (гравитация проекта 980)
- «Выстрел назад»: снаряд летит из-за спины + лёгкий отброс игрока вперёд
- Слои физики: 1=world, 2=player, 3=projectile (снаряды пролетают сквозь игрока)
- Сквош-стретч на прыжке/приземлении (пивот в ногах), камера со сглаживанием и границами уровня

## Как открыть
Godot 4.7.2 → Import → выбрать `K:\Platformer\project.godot`.

Запуск из консоли: `K:\Platformer\run.bat` (игра), `run.bat -e` (редактор), `run.bat -c` (headless-проверка).

## Источник кадров
Кадры скопированы из набора `K:\Test\Games\Assets\Bomzh\drifter-sprites-alpha-cleaned\` (папка `frames/`):
уже нарезанные RGBA PNG 384×512 с пивотом (192, 464). Полосы `animations/*.png` не используются.
При обновлении набора достаточно скопировать нужные папки анимаций в `Assets/Drifter/frames/` и перегенерировать `Assets/player_frames.tres`.
