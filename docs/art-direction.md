# Sewer visual direction

- Godot 4.7.2, orthographic side view, 1280×720 canvas, camera zoom 1.25.
- Existing Drifter player sprites preserved. Player is the highest-contrast moving silhouette.
- Painted wet blue-teal masonry, recessed arches, corroded ochre metal, localized amber light. No neon slime dots.
- Far: painted architecture; mid: translucent animated haze; near: suspended chains and pipes. Gameplay ledges remain readable.
- Environment artwork generated with Notion image generation, then cropped, chroma-key cleaned and normalized. No external stock imagery. Source images contain no third-party logos or text.
- Original character art remains from the repository; its provenance is unchanged.
- Texture resources embed PNG/JPEG bytes for complete GitHub transport; no manual generation needed on checkout.
